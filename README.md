# TrustXAI: Trustworthy Explainable AI for Cyber Threat Detection

A comprehensive research framework and project repository for **Trustworthy Explainable Artificial Intelligence (XAI) in Network Intrusion Detection Systems (NIDS)**.

---

## 📌 Repository Overview

This repository archives the research materials, literature survey, project presentations, and documentation for the **TrustXAI** project:

- **Research Papers**: Curated collection of 16 peer-reviewed post-2020 papers on XAI, NIDS, adversarial robustness, and interpretability.
- **Project Reports**: Phase 1 Project Report documentation (`.pdf`, `.docx`).
- **Presentations & Slides**: Review decks and presentation templates.
- **Literature Survey**: Comprehensive survey matrix (`Literature_Survey.xlsx`) and paper catalog (`PAPERS_INDEX.md`).

---

## 📑 Research Literature Catalog

A detailed index of all 16 papers is available in [PAPERS_INDEX.md](file:///c:/Users/Prasath/Desktop/Pictures/trustxai/PAPERS_INDEX.md).

### Key Research Themes:
1. **Base Baseline**: Explainable AI for Intrusion Detection Systems using MLP, LIME, and SHAP.
2. **Evaluation Frameworks**: Quantitative fidelity, stability, and consistency benchmarking for black-box XAI in NIDS.
3. **Adversarial Robustness**: SHAP-based attribution fingerprinting and adversarial defense.
4. **Counterfactual & Diffusion Explanations**: Actionable counterfactual explanations for security analysts.
5. **Ensemble & Advanced Architectures**: CatBoost, EnsembleGuard, and Transformer-based threat attribution.
